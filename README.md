# GymDesk
A Gym Management System developed using PHP and MySQL for managing members, trainers, payments and gym activities. The main purpose of GymDesk is to simplify gym management processes digitally. It reduces manual work and helps maintain records securely and efficiently.

# Techonologie used:

- PHP
- MySQL
- HTML
- CSS
- JavaScript

# Features:

- Admin Dashboard
- User Dashboard
- Payment Method
- Secure Login system
- Responsive Designs
- Membership Plans

# Authentication:

The System includes secure login authentication for Admin and User both:
    - Username based Login
    - Password protection
    - Session handling

Through this project, I learned:
    - PHP CRUD Operations
    - Database Management
    - Authentication System
    - Frontend & Backend Integration
    - Responsive Design
    - Project Structure Management
